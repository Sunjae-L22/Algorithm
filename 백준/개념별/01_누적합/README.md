# 누적합

학습 질문: 여러 구간의 합을 반복 계산하지 않으려면?

값이 바뀌지 않는 배열에서 여러 구간의 합을 구할 때 사용한다. 한 번 O(N) 시간과 공간으로 누적합을 만들면 각 구간 합은 O(1)에 구할 수 있다.

## 끝점을 어떻게 정의할까?

[2559 수열 풀이](2559/README.md)에서는 S[i]에 i번째 값까지 포함한다. [l, r]의 합은 l=0이면 S[r], 그 밖에는 S[r]-S[l-1]이다.
다른 관례로 P[0]=0, P[t]=앞 t개 값의 합으로 두면 같은 구간의 합은 P[r+1]-P[l]이다. 두 식은 배열 인덱스의 뜻이 다르다.

## 다시 풀 때

K=N이면 첫 구간 하나만 존재한다. K=1이면 각 원소가 하나의 구간이다. 모든 합이 음수여도 실제 구간에서 최댓값을 선택해야 한다.
구간 길이가 고정되어 있고 최댓값 하나만 필요하면 직전 구간 합을 갱신하는 슬라이딩 윈도우로 추가 배열을 줄일 수 있다.
