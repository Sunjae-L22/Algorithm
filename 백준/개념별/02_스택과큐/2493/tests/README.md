# 테스트 출처

- `sample01`: BOJ 공식 예제 1
- `edge01`: 자체 제작: 탑 하나
- `edge02`: 자체 제작, 높이가 증가해 수신 탑이 모두 없음
- `edge03`: 자체 제작, 높이가 감소해 바로 왼쪽에서 수신
- `edge04`: 자체 제작, 하나의 높은 탑이 대기 중인 세 신호를 수신

추가 입력은 같은 이름의 .in/.out 쌍으로 저장한다. 기댓값을 별도로 계산하고 출처를 기록한다.
비교 방식은 각 줄 끝의 공백과 마지막 줄바꿈만 무시한다. 실수 오차·다중 정답 문제는 별도 검증기가 필요하다.
