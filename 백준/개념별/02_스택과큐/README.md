# 스택·큐·덱

학습 질문: 최근 상태와 처리 순서를 어떤 구조로 관리할까?

## 단조 스택으로 가장 가까운 탑 찾기

[2493 탑](2493/README.md)에서는 답을 기다리는 탑의 인덱스를 저장한다. 오른쪽부터 읽으며 현재 탑보다 낮은 탑을 꼭대기부터 꺼낸다. 이미 살펴본 구간에서는 수신 탑을 만나지 못했으므로, 꺼낼 때 만난 현재 탑이 가장 가까운 답이다.

스택에서 어떤 값을 꺼내도 되는지는 문제마다 다르다. 두 가지를 먼저 정한다. **무엇을 기다리는가? 어떤 조건에서 그 답이 확정되는가?** 2493에서는 서로 다른 높이가 주어지므로 작은 탑만 꺼내면 된다. 높이 중복을 허용하는 변형이라면 같은 높이가 수신할 수 있는지부터 확인한다.

원소를 한 번씩만 넣고 꺼내면 전체 O(N)이다. 답을 원래 위치에 기록할 문제에서는 인덱스를 보관해 배열을 다시 검색하는 비용도 피한다.
