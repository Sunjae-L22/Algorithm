# 설치 검증 기록

2026-11-23, macOS, Python 3.11.9, markdown-it-py 4.2.0.

- 임시 합성 문제를 사용하는 회귀 테스트 14개 통과.
- 빈 풀이, 없는 테스트·누락된 기댓값, 오답, 시간 초과가 성공으로 기록되지 않음을 확인.
- 로컬 통과가 AC로 승격되지 않으며, AC 근거·완성 노트 없이는 정리 완료가 되지 않음을 확인.
- 코드·테스트·노트 변경 후 이전 검토가 만료되고, 오래된 인덱스가 검사에서 거부됨을 확인.
- BOJ와 solved.ac ID를 자동으로 동일시하지 않는 기존 해결 목록 제외 동작 확인.
- 복습 기한이 된 문제의 우선 추천 확인.
- 합성 글에서 초안 생성 → 준비 조건 검사 → 복사본 생성 동작 확인.
- 없는 이미지, 변경된 풀이 근거, 준비 완료 후 변경된 원고의 인계 거부 확인.
- 실제 후보 13개와 시작 폴더 1개의 기록 검사 통과. Python 문법·JSON·문서 내부 링크 확인.

실제 사용자 풀이의 BOJ 채점, 실제 티스토리 원고·이미지 제작, 공개 발행은 이번 설치 검증의 대상이 아니다.
2559의 코드는 미작성 상태이며 정답 실적으로 기록하지 않았다. 블로그 준비 검사는 글의 기술적 정답이나
이미지의 시각 품질을 자동으로 보증하지 않는다.

계정 조회는 브라우저에서 실제 공개 프로필과 해결 목록을 읽었다. 이 관측은 solved.ac에 표시된 시점의
기록이며 아직 반영되지 않은 BOJ 제출을 포함한다고 보장하지 않는다. API 자동 연동은 구현하지 않았다.
