# 선재의 문제 수첩

## 목적

문제를 푼 개수보다 지금 무엇을 생각하고 있고, 무엇을 다시 봐야 하는지 보여준다.
Algorithm의 실제 기록을 중심으로 현재 풀이·보관함·개념·복습·글감을 오갈 수 있는 개인 작업 공간이다.
정답 풀이와 핵심 알고리즘 힌트는 기본 화면에 노출하지 않는다.

## 시각 계획

- 종이: `#FFFFFF`, 책상: `#F3F6F6`, 잉크: `#263D45`, 보조: `#61757C`.
- 책갈피: `#235F59`, 메모지: `#F3EDBE`. 옅은 황색은 메모 한 곳에만 사용한다.
- 본문은 Apple SD Gothic Neo / Noto Sans KR 계열, 한국어 제목은 같은 계열의 얇고 넓은 크기 대비.
  작은 숫자와 날짜도 본문 계열을 유지한다. serif나 monospace를 장식으로 섞지 않는다.
- 왼쪽의 얇은 서가, 중앙의 넓은 문제 페이지, 오른쪽 좁은 공부 메모로 시선이 이어진다.
- 문제 제목이 주인공이다. 커다란 통계 카드·그라데이션·성과 차트는 사용하지 않는다.
- 8px 중심 간격, 본문 16px, 상태·조작 14px 이상, 제목 48px.
- 테이블은 문제명·상태·학습 목적이 한 줄에 읽히게 한다. 표시 폭이 좁으면 의미 단위로 접는다.
- 버튼과 패널의 모서리는 기능에 따라 8px·14px·22px로 구별한다. 그림자는 떠 있는 메모와 대화상자에만 쓴다.

```text
서가                오늘의 페이지                         읽기 기록
이름/작은 표식       날짜 / 검색                           진행·완료 숫자
오늘의 공부         지금 푸는 실제 문제                   오늘의 메모
문제 보관함         문제 열기 / 기록 보기                 저장 상태
개념 지도           다음 문제 목록                        복습 안내
복습 노트
글감 모음
프로필 관측값
```

## 계획 검토

초기 구상의 큰 요약 숫자와 반복 카드가 일반적인 대시보드처럼 보여 제거했다.
실제 문제명, 좁은 필기 여백, 작은 책갈피를 화면의 특징으로 삼는다.
불필요한 장식 번호·격언·영문 대문자 라벨을 쓰지 않는다.
사용자의 독립 풀이를 위해 개념 설명은 필요한 경우에만 펼친다.

## 검수 기준

데스크톱과 모바일의 잘림·가독성, 키보드 탐색·대화상자 포커스,
실제 기록의 개수·상태, 저장 후 새로고침, 빈 검색·빈 복습의 다음 행동을 확인한다.
테스트 통과·BOJ 판정·정리 완료를 서로 다른 값으로 표시한다.
