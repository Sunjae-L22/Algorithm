# 선재의 문제 수첩

[웹에서 열기](https://sunjae-problem-notebook.vongole.chatgpt.site)

사이트 소유자의 ChatGPT 계정으로 로그인해서 사용하는 개인 대시보드다.
같은 계정으로 접속하면 다른 기기에서도 저장한 메모와 책갈피를 읽을 수 있다.

## 다섯 페이지

- 오늘의 공부: 현재 문제, 다음 후보, 오늘 메모, 기한이 된 복습.
- 문제 보관함: 번호·이름·개념 검색, 상태·개념 필터, 책갈피.
- 개념 지도: 15개 개념의 연결 문제와 GitHub 개념 노트.
- 복습 노트: 실제 검토 기록에서 계산한 다음 복습일.
- 글감 모음: 기록에 있는 글감 후보와 직접 모아둔 문제별 생각.

문제를 누르면 내 생각, 풀이 기록, 연결된 페이지를 펼칠 수 있다.
풀이와 핵심 힌트는 자동으로 표시하지 않는다. 메모는 **저장**을 눌러 확정한다.
여러 창에서 같은 메모를 수정하면 이전 버전의 덮어쓰기를 거부한다.
충돌 안내가 나오면 현재 작성한 내용을 복사해 둔 뒤 새로고침하고 이어서 저장한다.

## 두 기록의 저장 위치

| 기록 | 원본 | 웹 반영 |
|---|---|---|
| 문제·학습 목적·테스트·온라인 판정·검토·복습일 | Algorithm의 각 `meta.json`과 후보 목록 | `index` → 검수 → `master` 푸시 → 웹 새로고침 |
| 프로필 티어·전체 해결 수 | 확인 날짜가 있는 `config.json` | 같은 공개 스냅샷에 포함. solved.ac 실시간 조회 아님 |
| 문제 메모·오늘 메모·책갈피·다음 문제·글감 선택 | Sites의 계정별 비공개 D1 저장소 | 저장 후 다른 기기에서 다시 접속 또는 새로고침 |

GitHub에서 웹으로 학습 기록을 읽는다. 웹 메모는 GitHub 파일을 수정하거나 자동 커밋하지 않는다.
공개 풀이 노트에 옮기려면 “수첩에 적은 내용을 포함해 풀이를 정리해줘”라고 요청하고 해당 메모를 제공한다.
웹만으로 백준 AC 또는 정리 완료를 만들지 않는다. 과거 solved.ac 해결 기록과 이 파이프라인의 정리 완료도 구별한다.

```bash
python3 study-workflow/scripts/study.py index
python3 study-workflow/scripts/study.py check
python3 -m unittest discover -s study-workflow/tests -v
# 변경한 학습 파일과 dashboard-data.json을 명시적으로 커밋·푸시
```

접속 시 GitHub 공개 JSON을 읽으며 짧은 서버 캐시(20초)를 사용한다. 새로고침 버튼은 이 캐시를 우회한다.
GitHub 자체 전파 지연은 있을 수 있다. 연결에 실패하면 보관한 스냅샷과 경고를 표시한다.
개인 저장소에 연결하지 못하면 저장 버튼을 비활성화하고 실패를 알린다.
인터넷 연결이 필요하며, 자동 제출·배경 동기화·복습 알림 예약은 하지 않는다.

## 구현 유지보수

이 폴더에는 공개 데이터 계약과 디자인 기준을 둔다. 웹 앱 소스와 배포 버전은 Sites의 별도 소스 저장소에서 관리한다.
데이터 생성은 `study-workflow/scripts/dashboard_export.py`, 갱신·검사는 기존 `study.py`에 통합되어 있다.
개인 메모·로그인 정보·계정 캐시는 공개 JSON에 포함하지 않는다.
